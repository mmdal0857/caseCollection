## Question

[코어 루프 확정](03-core-loop.md)에서 종이 위로 확정한 루프가 실제로 재미있는가 — /prototype으로 페이퍼 또는 코드 프로토타입을 만들어 반응을 확인한다. 검증 대상 3가지:

1. **어휘 게이트 퍼즐**: 보유 단서 카드로 슬롯을 채우는 추리 + 근접도("몇 개 맞음") + 3개 단위 확정이 주는 긴장·진전감.
2. **문맥 태그 평가 체감**: 같은 카드가 배경 상태에 따라 다른 답이 되는 구조가 "배울 수 있는 시스템"으로 느껴지는가, 아니면 자의적으로 느껴지는가. (프로토용 임시 태그 규칙은 던져도 됨 — 정식 설계는 [문맥 태그 의미론 설계](12-context-tag-semantics.md))
3. **런 긴장감**: case 3건 + 보스 미니 런에서 인터루드 이벤트·BAD 엔딩 리스크가 카드 선택에 전략적 무게를 싣는가.
4. **DOM juice 충분성** ([웹 스택과 디바이스 타깃](05-web-stack.md) 결정의 검증 항목): 시너지 발동·카드 연출을 Svelte 내장 transition/FLIP/motion만으로 구현했을 때 타격감이 충분한가. 부족하면 PixiJS 카드 레이어 해치를 발동하고 05 결정에 반영.

프로토타입이 루프를 반증하면 03의 결정을 재개정한다(지도 갱신). 프로토 자산은 티켓에서 링크.
