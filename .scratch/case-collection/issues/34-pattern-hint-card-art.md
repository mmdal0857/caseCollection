# 패턴·힌트 카드 시각 규칙 확정

Status: closed
Labels: wayfinder:grilling
Assignee: Codex
Blocked-by: 13

## Question

[13](13-card-art-pipeline.md)이 확정한 "명사는 생성·형용사는 계산" 원칙과 스타일 A(플랫 셀 누아르)는 단서(clue) 20장에서 전량 검증됐다(2026-07-27 완료). 그러나 `scripts/cardart-manifest.jsonl`을 직접 대조하면 패턴 4종·힌트 2종은 여전히 `category:"adjunct", enabled:false`로 남아 있고, 그 옆에 적힌 사유("시각 규칙 별도 결정")가 2026-07-25 이후 한 번도 재개되지 않았다.

패턴 카드는 단서 카드와 성격이 다르다 — [04](04-card-schema.md)의 정의대로 "가설 선언 어휘"이지, 원문에서 추출한 사물이 아니다(`locked-room`·`false-alibi`·`staged-disappearance`·`invisible-man`, `content.ts`의 `patterns` 딕셔너리 확인). 단서에 적용한 "사물 사진" 문법을 그대로 적용할 대상 자체가 없다.

확정할 것:

- **패턴 카드가 무엇을 그리는가**: 사물이 없으므로 13의 원칙("용도 아닌 사물을 그린다")을 곧이곧대로 못 쓴다 — 구조적 도상(다이어그램형), 상징 오브제(가설을 은유하는 새 사물 1개를 고르기), 타이포그래피 중심 중 무엇을 채택할지.
- **힌트 카드 2종의 정체**: 매니페스트에 남은 힌트 2건이 정확히 무엇을 가리키는지 먼저 확인한다 — [10](10-acquisition-detail.md)에서 기각된 "힌트 카드 크래프팅"과 다른 개념인지, 남겨둔 이유가 지금도 유효한지.
- **스타일 일관성 범위**: `docs/art/style-key.png`가 사물 사진 대상(실·섬유)으로 만들어졌다 — 패턴 카드가 같은 키를 `--image-references`로 그대로 참조해도 13이 실측한 드리프트 0을 유지하는지, 아니면 패턴 전용 보조 키가 필요한지.
- **폴백과의 관계**: `CardChip`에 이미 슈트별 폴백 실루엣이 있다 — 패턴 4장이 전용 아트 없이 폴백만으로 출시돼도 되는지(MVP 게이트를 낮추는 선택지), 아니면 [08](08-mvp-scope.md) §⑤ "아트=전부"가 패턴 4장의 전용 아트까지 명시적으로 요구하는지 판정한다.

## Resolution

패턴 4종과 힌트 2종은 **아트가 붙는 카드가 아니라 의미를 직접 전달하는 UI 어휘**로 확정한다.

- 패턴(`locked-room`·`false-alibi`·`staged-disappearance`·`invisible-man`)은 원문에서 추출한 사물이 아니라 가설 선언 어휘다. 플레이 화면에서는 기존 `pattern-chip`, 컬렉션에서는 이름·설명 중심 항목으로 표시하며 전용 일러스트나 `CardChip` 폴백을 붙이지 않는다.
- 힌트(`analysis`·`tipoff`)는 [10](10-acquisition-detail.md)에서 유예된 힌트 카드 크래프팅이 아니라 현재 `content.ts`의 런 한정 액션인 **감식 의뢰**와 **익명 제보**다. 기존 `hint-btn` 액션으로 표시하고 카드 아트 대상으로 승격하지 않는다.
- 따라서 `docs/art/style-key.png`는 사물 단서 생성에만 사용한다. 패턴 전용 보조 스타일 키와 패턴·힌트 이미지 생성은 하지 않는다.
- `scripts/cardart-manifest.jsonl`의 6개 ID는 콘텐츠 누락 검증을 위해 삭제하지 않는다. 대신 `category:"adjunct"`, `enabled:false`, `artPolicy:"semantic-ui"`로 보존하고, 생성 대상으로 오해하게 만드는 `description`·`composition` 프롬프트 필드는 제거한다. 검증기는 단서에만 생성 프롬프트를 요구하고 adjunct에는 이 정책을 명시적으로 강제한다.
- [08](08-mvp-scope.md)의 24장 콘텐츠 볼륨(단서 20 + 패턴 4)은 그대로다. §⑤의 “아트=전부”는 실제 아트 표면인 단서 카드·배경·인물·UI 장식의 완성 범위이며, 가설 칩과 힌트 액션을 억지로 그림 카드로 바꾸라는 요구로 해석하지 않는다.

**/ 기각**: 패턴용 구조 도상·상징 오브제·타이포그래피 일러스트, 패턴 전용 스타일 키, 힌트 액션의 카드화, disabled adjunct 행 삭제. 마지막 선택지는 매니페스트의 전체 콘텐츠 ID 대조 계약을 깨뜨리므로 보존 정책으로 대체했다.
