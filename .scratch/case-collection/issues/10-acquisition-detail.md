# 획득 구조 세부 확정

Status: closed
Labels: wayfinder:grilling
Assignee: MMDAL (fable session, 2026-07-19)
Blocked-by: 09

## Question

코어 루프(03)에서 확정한 방향 — 어휘 게이트 + 소모형 힌트 카드, 획득은 학습형(게스트 단서) + 보상팩 혼용 — 위에서 획득·진행 경제의 세부 구조를 확정한다. [획득 구조 레퍼런스 리서치](09-acquisition-reference-research.md)의 후보 구조(MVP 권고 조합: 어휘 확정 게이트 + 고정 공급 기회비용 + 선택형 단서팩·무중복 편향)를 재료로: 랜덤과 결정성의 배분, 획득 시 의사결정(선택·드래프트·크래프팅 여부), 소모형 힌트 카드의 지급 경제, 진행 곡선(초반 스타터 컬렉션 → 후반 어휘 완성)을 결정한다.

03의 연속 런 확정으로 범위 추가: **런 경제** — 게스트 단서의 영구화 시점(case 클리어 즉시 vs 런 완주 보상), 보상팩·힌트 카드의 지급 지점(case 클리어/인터루드/런 완주), BAD 엔딩으로 끝난 런의 획득물 처리(전량 보존 vs 일부 소실)를 함께 확정한다.

## Resolution

2026-07-19, 그릴링 세션(MMDAL × Fable/Opus). 리서치 [획득 구조 레퍼런스](09-acquisition-reference-research.md)의 MVP 조합 권고를 재료로 확정. 수치는 잠정치 — [코어 루프 프로토타입](11-core-loop-prototype.md)에서 튜닝.

- **획득 프레임 (권고 1+3+2 조합)**: ① 어휘 확정 게이트가 뼈대(가설→확정 승격) + ③ 고정 공급 진열·기회비용(Dominion형, 결정론 저부담) + ② 선택형 단서팩·무중복 편향(설렘을 결정론과 하이브리드). 권고 4(수사 렌즈)·5(힌트 크래프팅)는 MVP 이후 확장.
- **영구화 = [카드 스키마](04-card-schema.md)의 보유×검증 2축에 매핑 (하이브리드)**:
  - **보유(획득)는 즉시** — case 클리어 시 그 판에서 쓴 게스트 단서가 즉시 컬렉션에 "보유(가설 상태)"로 편입. 카드 수는 계속 늘 수 있는 개방형.
  - **검증(확정)은 런 완주 시** — 런을 완주(보스 포함)해야 그 런에서 보유·사용한 카드들이 "검증(확정)"으로 승격. 검증 어휘만 더 복잡한 case의 게이트를 연다.
- **BAD 엔딩 처리 (승격 전무, 깔끔한 베팅)**: BAD 엔딩으로 런 조기 종료 시 **검증 승격 0**. 단 **보유 카드는 어떤 경우든 전량 보존** — 배운 것(보유)은 남고 마스터리 확정(검증)만 베팅 대상. "학습은 남고 시간 낭비감은 없다" + 인터루드·보스 직전 긴장 극대화.
- **지급 지점 (런 타임라인 3분할)**:
  - **case 클리어 → 게스트 단서 보유 획득** (학습 국면).
  - **인터루드 → 수사 포인트로 고정 진열 정조준 구매**(단서 카드 + 힌트 카드), 기회비용 결정 국면. Dominion형 고정·공개 진열, 런마다 세트 교체.
  - **런 완주 → 선택형 팩**(설렘 보상) + 검증 승격.
- **수사 포인트(진열 구매 화폐) — 고정 지급+성과 보너스, 런 한정**: case 클리어마다 기본액 지급(구매 계획 가능한 바닥) + 가산 보너스(힌트 미사용·적은 제출 횟수 등 — 감점이 아닌 가산이라 오답의 문맥-태그 오염과 **이중 처벌 회피**). 런 종료 시 소멸 → 인터루드마다 "지금 쓸까 아낄까"가 실제 기회비용.
- **소모형 힌트 카드 경제 — 진열 구매 + 이벤트 지급, 런 한정**: 주 경로는 인터루드 진열에서 수사 포인트로 구매(단서 구매와 경합 → 기회비용 강화), 보조로 인터루드 이벤트가 간헐 지급. 미사용분은 런 종료 시 소멸(아끼지 말고 쓰라는 압력). 완주 팩은 컬렉션 카드 전용(힌트 미혼입 — 런 한정 소모품이 영구 보상 국면에 안 낌).
- **완주 팩 구조 — 5중 1 + 미보유 가중치 + 승격권 폴백**: 후보 5장 중 1장 선택(보스 클리어 완주는 2장). 후보는 미보유 강한 가중치 + 이번 런에서 게스트로 쓴 계열 연관 편향(경험이 선택을 정보화). 완전 무중복이 아닌 가중치라 풀 성장에도 스케일. 전량 보유 시 후보가 "미검증 카드"로 대체되어 즉석 검증 승격권으로 기능(폴백).
- **진행 곡선 — 소수 스타터 + 런마다 진열 변주**: 스타터 = 슈트 4종 골고루 기본 단서 소수(잠정 8~12장, 첫 case 풀이 보장선), 패턴 카드 0장(플레이로 발견). 진행은 런마다 진열 세트만 교체(Vaccarino "하나만 변주" 원칙, 빌드타임 큐레이션). 장기 목표 = 보유율 → 검증율 순차 완성(04의 2축 도감). 카드 풀 성장 시 스타터는 고정, 공급(진열·팩 후보 풀)만 확장.
