# MVP Audio Implementation Plan

> **For Codex:** Execute in `.worktrees/data-contracts-extraction`. Keep generated
> candidates and reusable procedures project-local. Do not reuse Dead Letters
> prompts, finished audio, or worldbuilding assets. Do not commit, merge, or push
> without separate user approval.

**Goal:** Add two instrumental loops and seven semantic SFX with auditable
generation provenance, mechanical audio QA, explicit human selection, and a
browser runtime that always falls back to silence without changing game state.

**Architecture:** A project-local Higgsfield CLI generator downloads source candidates into an ignored
staging directory. A promotion command copies only explicitly human-picked
candidates into tracked `public/audio`, transcodes OGG/MP3, measures the final
files, hashes them, and writes `audio-manifest@1`. The Svelte runtime owns only
playback settings and event-to-sound mapping; the reducer never imports audio
and therefore remains deterministic under mute, autoplay rejection, or decode
failure.

**Models and usage boundary (revised by user 2026-07-28):**

- Music: Higgsfield `sonilo_music` (Sonilo Music), because the job type exposes
  an explicit duration for loop candidates.
- SFX: Higgsfield `seed_audio` (Seed Audio 1.0), 48 kHz WAV output.
- Higgsfield Terms of Use §4.4 does not restrict commercial use of Outputs, but
  rights clearance remains the user’s responsibility. Re-check the current
  terms before every commercial release.
- The earlier local ACE-Step/Stable Audio set passed mechanical QA but failed
  actual user listening and is prohibited from promotion.
